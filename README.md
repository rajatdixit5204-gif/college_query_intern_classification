
# College Query Intent Classification System

An AI-based application that classifies student questions
into six college-related intent categories.

## Categories
- Admission
- Fees
- Exam
- Hostel
- Scholarship
- Timetable

## Technology
- Python
- TF-IDF
- Logistic Regression
- Scikit-learn
- Streamlit

## Run locally
Install requirements:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Project Files
- app.py: Streamlit web application
- models/: Trained ML model
- dataset/: Project dataset
